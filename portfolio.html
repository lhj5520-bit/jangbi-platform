Overview

무엇을 만들었나

건설장비 임대·운영 사업의 전 과정을 디지털화한 웹 기반 관리 플랫폼입니다. 배차 등록부터 거래명세서 발행, 부가세 신고, 세무 일정 관리까지 현업에서 필요한 모든 업무를 하나의 앱에서 처리할 수 있도록 설계했습니다.

🎯

개발 배경

엑셀과 수기 장부로 처리하던 배차·정산 업무를 체계화하고, 세무 마감 누락을 방지하기 위해 직접 기획·개발한 사업 관리 툴

👤

사용 대상

건설장비 임대 개인사업자 및 소규모 법인. 현장별 배차, 거래처별 청구, 월별 세무 신고를 직접 관리하는 실무자

⚡

핵심 가치

반복 작업 자동화 (거래명세서 자동 생성, 부가세 자동 계산), 실시간 데이터 동기화, 모바일·PC 어디서나 접근 가능

Features

주요 기능

업무 흐름에 맞게 설계된 8개 핵심 모듈

📊

대시보드

오늘의 배차 건수, 이번달 매출, 미수금 현황을 한눈에 확인. 동적 세무일정 위젯으로 마감 임박 항목 자동 알림.

메인 허브
🚛

배차관리

장비·거래처·현장명·단가를 등록하고 날짜별 배차를 관리. 체크박스 선택 후 다른 날짜로 일괄 복사 가능.

핵심 기능
📋

배차내역서

날짜·거래처·장비별 배차 내역 일람표. 가동 시간·매출액 집계, 인쇄·공유 기능 내장. 가로 스크롤 지원.

정산 보조
✅

작업확인서

일별 작업 현황 확인서 자동 생성. 배차 데이터와 연동되어 날짜·현장·시간 정보 자동 채움. 인쇄 최적화.

문서 자동화
🧾

거래명세서

거래처별 기간 필터 → 자동 명세서 생성. 도장 이미지 삽입, 카톡 공유(JPG), 인쇄/PDF 내보내기 지원.

청구 문서
🏦

통장내역

수입·지출 내역 입력 및 월별 집계. 카테고리별 분류, 잔액 자동 계산. 세금계산서와 연동한 미수금 추적.

자금 관리
📈

부가세 관리

1·2기 예정/확정 4개 구간 자동 계산. 매출세액·매입세액·납부세액 실시간 집계. 납부 기록 저장.

세무 관리
💼

개인사업자 관리

연도별 매출·매입·환급부가세·카드매입부가세 입력. 예상 납부 부가세 자동 산출. 업체별 비교 표.

Dev Highlights

주요 개발 포인트

단순 CRUD를 넘어 실무 요구사항을 해결한 기술적 도전들

배차 일괄 복사

체크박스로 여러 배차 선택 → 날짜 변경 복사 시 dispatches와 daily_logs를 각각 순서대로 삽입해 ID 매핑 유지

도장 크로스디바이스 동기화

도장 이미지를 localStorage + Supabase DB 이중 저장. 페이지 로드 시 localStorage 우선, 없으면 DB fallback

동적 세무일정 위젯

오늘 날짜 기준으로 원천세·부가세·종소세 마감일 자동 계산. 7일 이내 임박/기한 초과 상태 실시간 표시

거래명세서 자동 생성

일별 배차 데이터를 기간·거래처로 필터링해 명세서 자동 완성. html2canvas로 JPG 변환 후 카톡 공유

부가세 자동 계산

매출세액 - 매입세액 - 환급부가세 - 카드매입부가세 공식으로 예상 납부액 실시간 산출

인쇄 최적화

@media print CSS로 버튼/네비게이션 숨김, 거래명세서 인쇄 레이아웃 별도 설계. A4 비율 자동 조정
